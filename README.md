# The Funniest Toaster Error Message

One original toaster error message, written for the [Make.fun bounty](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd).

`main.py` writes the error message to `/output/entry.txt`:

> ERROR: Toasting cancelled. The bread looked at me funny first.

Run it with `python3 main.py`.
